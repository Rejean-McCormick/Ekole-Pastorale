# ARK-21 — Témoin, vertus et attestations

Le modèle natif de témoignage est séparé du modèle des unités (ARK-20). Sources, vertus, œuvres et récits merveilleux ont des statuts distincts; aucune approbation de canonisation ni miracle n’est déduite automatiquement. Générer les KQ/KP/KA/KS v11 et vérifier les sources avant de bâtir un dossier canonique.
